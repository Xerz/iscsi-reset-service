Конфигуратор

Загрузка
Сохранённая revision отличается от загруженной сервисами. Перезапустите весь Custom App.

Статус

Текущее состояние конфигурации и discovery.

Правила сохранения

  • TrueNAS используется только для read-only discovery.
  • Ссылки на target, extent, LUN и dataset перепроверяются перед записью.
  • Active и incomplete releases блокируют несовместимые изменения.
  • Новый YAML применяется только после restart всего Custom App.

Сеть

Portal, доступ к Admin API и именование releases.

Publisher

Master target и соответствие volumes существующим LUN.

Клиенты

Отдельный target и набор writable clones для каждого ПК.

YAML

Расширенный режим редактирования config.yaml.

После проверки сервер канонизирует YAML; комментарии не сохраняются.
